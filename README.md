## 📌 О проекте

Репозиторий содержит исходный код и структуру моего персонального сайта-визитки. Проект разработан с нуля: от проектирования минималистичного UI в природной эстетике до чистой адаптивной верстки и посадки на **CMS WordPress**.

### Ключевые особенности реализации:
* **Семантическая и адаптивная верстка:** построение сеток на Flexbox и CSS Grid, корректный скейлинг от широкоформатных мониторов до мобильных экранов (`320px+`).
* **Интерактивные модальные окна портфолио:** написан кастомный PHP-шорткод `[work_popup_btn]`, который динамически подтягивает данные каждого кейса и инициализирует внутри попапа слайдер **Swiper.js** с навигацией и пагинацией.
* **Удобное управление контентом (ACF):** все секции, карточки работ, описания и галереи слайдов выведены в админ-панель WordPress через произвольные поля **Advanced Custom Fields**.
* **Производительность:** абстрактная векторная графика (SVG) и сжатые растровые изображения в формате **WebP** для мгновенной загрузки без потери качества.
